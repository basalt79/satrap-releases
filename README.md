# satrap Maven repository

Public Maven repository for satrap-java-lib, published by its CI. Do not edit
by hand – the branch is rewritten on every publish.

```xml
<repository>
  <id>satrap-releases</id>
  <url>https://raw.githubusercontent.com/basalt79/satrap-releases/maven</url>
  <snapshots><enabled>true</enabled></snapshots>
</repository>
```
